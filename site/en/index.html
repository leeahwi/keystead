Tour

One screen at a time

01 · Vault

The biggest button copies the password

The window opens with the cursor in the search box. Type two or three letters and ↵ copies the password.

Each entry starts with one blue button that copies the password. Below it sit username, the current one-time code and a button that opens the site.

02 · Quick search

⇧⌥Space from any app

A small window opens on top of whatever you're using. Narrow it with the space chips, pick with ↑↓, and ↵ copies the password.

Copied values are cleared after 20 seconds. On Windows the shortcut is Alt+Shift+Space.

03 · Unlock in quick search

Locked? Unlock right there

No trip to the main window. Quick search asks for the master password, then the phone code, and goes straight to search once it's open. On a Mac, Touch ID can stand in for the master password.

04 · Health check

Reused passwords, with a way to fix them

Weak passwords and passwords used in more than one place are listed. The password row says which entry it matches, such as Slack.

The make-a-new-password button opens the editor with a fresh one. The check runs on this computer only.

05 · Editor

Note how you sign in, too

Enter the website and it suggests a title and sign-in method. Pick the site's own password and any of Google, Naver, Kakao, Apple and other providers.

The generator sits right next to the password and shows strength in bits. Fields you rarely need are folded away.

Get started

Setup takes about two minutes

You spread three keys across your head, a sheet of paper and your phone. After that, the master password and the phone code are all you need.

1

Pick a master password

Enter it twice. A long sentence you can remember works best. It is never stored anywhere.

Master password
2

Write down the Secret Key

Copy the Secret Key from the screen onto paper and confirm its last 4 characters. It's also saved in this computer's Keychain.

Example Secret Key
SV1-AEBAG-BAFAY-DQQCI-KBMGA-2DQPCA
3

Add your phone

Scan the QR code with an authenticator app, such as Google or Microsoft Authenticator, and enter the 6-digit code.

6-digit phone code

Keep the Secret Key paper and the OTP key away from the computer. They're the only way back in after you change computers or lose your phone. Write the 4-letter OTP key groups shown next to the QR code on the same sheet, and you can add it to any authenticator app later.

Features

Close the window, the shortcut still works

Keystead keeps running after you close its window: in the Dock on a Mac, in the notification area on Windows. To quit, press ⌘Q on a Mac or use the tray icon on Windows.

Touch ID and Windows Hello

Turn it on in settings and open with a fingerprint instead of the password. Windows Hello also takes face or PIN. After 3 days or a restart, the password is asked again. With “Touch ID only” on, the phone code is skipped too. It's off by default.

Locks when you step away

It locks on sleep, screen lock and user switch, after the idle time you choose (1, 5, 15, 30 or 60 minutes), and always 12 hours after unlocking. ⌘L locks it now.

Security

A leaked file won't open

The key only comes out when the master password and the Secret Key are both there. The app also checks the phone code before it shows anything.

What it defends against

Password guessingArgon2id costs 512 MiB of memory and about 0.6 s per guess (Apple M series).
Leaked fileThe 128-bit Secret Key goes into the key with the password, so even a weak password can't be brute-forced.
Reading contentsAES-256-GCM over everything, titles, URLs, notes and space names included.
TamperingChange one byte and the file won't open.
RollbackA save counter is also kept in the Keychain; an older file brings up a warning.
Leaked passwordChanging the master password also makes a new vault key, and restore points that open with the old password are deleted.
Repeated failuresFrom the 3rd failure, the wait doubles each time, up to 15 minutes.
ClipboardCleared after the set time and flagged so clipboard history skips it.

Saved files are also scanned for leftover plaintext. Vaults written by the Mac, Windows and Python code all pass.

What it can't stop

  • A computer already taken over by malware (keyloggers, programs that read memory)
  • An unlocked computer left unattended
  • Other apps reading the clipboard during the few seconds a value is there
  • The phone code is a check inside the app, not encryption. Someone with the file, the password and the Secret Key could open the vault with their own program. Against a leaked file, the Secret Key is the real second factor.
  • Touch ID and Windows Hello are a convenience. Another program running as you can ask for your fingerprint too. Windows Hello includes the Windows PIN, so with “Windows Hello only” on, the PIN alone opens the vault.

Backup, move, restore

The vault is one file

So backing up, moving and restoring all come down to handling that file.

What's where

The keys are split between your head, paper and phone. The vault file lives only on this computer, and a locked copy goes to a USB stick or cloud folder only when you put it there.

Backup

Back up two things: the vault file and the Secret Key paper. The file is always encrypted, so any USB stick, disk or cloud folder will do. Settings can save a copy wherever you choose.

The file is at ~/.securevault/vault.svlt on a Mac and %USERPROFILE%\.securevault\vault.svlt on Windows.

Move to another computer

Install Keystead on the new computer but don't open it yet; opening it first starts a new vault. Put the file into .securevault in your home folder, then open the app. Mac to Windows works the same way.

Restore an earlier version

In settings, pick a version by save number and time. Only entries and spaces go back; the version you replaced stays in the backups.

If the old-file warning shows up when you haven't restored anything, someone may have swapped the file. Choose not to open it and check the file.

If you lose something

The master password can't be recovered. Nothing is handed to anyone else, so if you lose it, not even the developer can help.

FAQ

Questions

Can I use it on both Mac and Windows?

Both apps open the same vault file. There's no sync, though, so you move the file yourself. Changes made to the same vault on two computers aren't merged.

Why does the OS warn me the first time?

The builds aren't notarized by Apple or signed for Windows yet. Every release's file hashes are signed instead, so you can check your download yourself; see below.

Has the Windows app been tested?

It's built and format-checked on Windows CI runners, but it hasn't run on a real Windows PC yet. The same goes for the 0.8.0 quick search window and Windows Hello. If something looks off, please open an issue.

How do I hear about new versions?

The app never checks for updates. New versions and their notes appear on the releases page. The vault file format didn't change in 0.8.0.

What language is the app in?

Korean. This page and the README are also in English.

How do I remove everything?

Delete the app, the .securevault folder in your home folder, and the securevault items in Keychain Access (Credential Manager on Windows). If you also destroy the emergency kit paper, that vault can't be opened again.

I found a security problem

Please report it privately to the repository owner rather than in a public issue, since others could use it before it's fixed. You'll hear back within 7 days, and a fix ships within 90 days at the latest. Never send real passwords, Secret Keys or vault files. See the security policy.

Make a vault on your own computer

You'll be set up in about three minutes. The builds aren't code-signed yet, so the OS blocks the first launch once.

Download for Windows
Check that the download is genuine (recommended)

Someone could re-upload Keystead with malware inside, so every release ships SHA256SUMS and its signature SHA256SUMS.sig. Put the downloaded files in one folder and run the repository's check script.

scripts/verify-release.sh ~/Downloads/keystead-v0.9.0
powershell -ExecutionPolicy Bypass -File scripts\verify-release.ps1 -Dir $HOME\Downloads\keystead-v0.9.0

If it prints 모두 확인했습니다 (all verified), the files are genuine. It fails when the version written in the signed list differs from the folder name (keystead-v0.9.0), so an older release can't pass as the latest; the public keys are in .github/release-signing.
